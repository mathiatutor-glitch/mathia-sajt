← Nazad na predmet
O čemu je predmet. Algebra pokriva kompleksne brojeve, polinome, matrice i determinante, sisteme linearnih jednačina i osnovne algebarske strukture (grupe, prsteni, polja). Svaki pojam prvo objašnjavamo rečima, zatim dajemo formulu i rešen primer.

1.Kompleksni brojevi

Kompleksan broj: z = a + bi (i² = −1). Moduo i argument:

|z| = √a² + b²    tg φ = baTrigonometrijski: z = |z|(cos φ + i sin φ)Moavrova formula: zn = |z|n(cos nφ + i sin nφ)
Zapamti
Konjugovano z̄ = a − bi; z · z̄ = |z|². Deljenje: pomnoži i brojilac i imenilac konjugovanim imeniocem.

2.Polinomi

Polinom P(x) stepena n ima najviše n nula. Bezuova teorema: P(a) = 0 ⇔ (x − a) deli P(x).

Vietove formule (kvadratna): x1 + x2 = −ba,   x1 · x2 = ca
Zapamti
Racionalne nule traži među deliocima slobodnog člana kroz delioce vodećeg koeficijenta.

3.Matrice i determinante

Matrica je pravougaona šema brojeva. Množenje: red puta kolona. Determinanta 2×2:

det = a·d − b·cInverzna 2×2: A−1 = 1det A · [ d, −b ; −c, a ]
Zapamti
Matrica je invertibilna ako i samo ako je det ≠ 0.

4.Sistemi linearnih jednačina

Gausov postupak: elementarnim transformacijama svodimo sistem na stepenasti oblik. Kramerovo pravilo (det ≠ 0):

xi = det Aidet A
Rešen primer — Kramer
Sistem: 2x + y = 5, x − y = 1.det A = 2·(−1) − 1·1 = −3x = det Axdet A = (5·(−1) − 1·1)−3 = −6−3 = 2,   y = 1
