Algebra

Kompleksni brojevi, polinomi, matrice, determinante i sistemi — korak po korak.
✦
← Nazad na predmet
O čemu je predmet. Algebra pokriva kompleksne brojeve, polinome, matrice i determinante, sisteme linearnih jednačina i osnovne algebarske strukture (grupe, prsteni, polja). Svaki pojam prvo objašnjavamo rečima, zatim dajemo formulu i rešen primer.

1.Kompleksni brojevi

Kompleksan broj: z = a + bi (i² = −1). Moduo i argument:

|z| = √a² + b²    tg φ = baTrigonometrijski: z = |z|(cos φ + i sin φ)Moavrova formula: zn = |z|n(cos nφ + i sin nφ)
Zapamti
Konjugovano z̄ = a − bi; z · z̄ = |z|². Deljenje: pomnoži i brojilac i imenilac konjugovanim imeniocem.

2.Polinomi

Polinom P(x) stepena n ima najviše n nula. Bezuova teorema: P(a) = 0 ⇔ (x − a) deli P(x).

Vietove formule (kvadratna): x1 + x2 = −ba,   x1 · x2 = ca
Zapamti
Racionalne nule traži među deliocima slobodnog člana kroz delioce vodećeg koeficijenta.

3.Matrice i determinante

Matrica je pravougaona šema brojeva. Množenje: red puta kolona. Determinanta 2×2:

det = a·d − b·c
Zapamti
Matrica je invertibilna ako i samo ako je det ≠ 0.

4.Sistemi linearnih jednačina

Gausov postupak: elementarnim transformacijama svodimo sistem na stepenasti oblik. Kramerovo pravilo (det ≠ 0):

xi = det Aidet A
Rešen primer — Kramer
Sistem: 2x + y = 5, x − y = 1.det A = 2·(−1) − 1·1 = −3x = det Axdet A = (5·(−1) − 1·1)−3 = −6−3 = 2y = 1

5.Matematička logika i skupovi

Iskazne operacije: ¬ (negacija), ∧ (konjunkcija), ∨ (disjunkcija), ⇒ (implikacija), ⇔ (ekvivalencija). Implikacija p⇒q je netačna samo kad je p tačno a q netačno.

A ∪ B,   A ∩ B,   A \ B,   |P(A)| = 2n  (za |A| = n)
Zapamti
De Morganovi zakoni: ¬(p ∧ q) ⇔ ¬p ∨ ¬q; ¬(p ∨ q) ⇔ ¬p ∧ ¬q. Dekartov proizvod: A×B = {(a,b) | a∈A, b∈B}.

6.Relacije

Binarna relacija ρ ⊆ A². Osobine: R refleksivnost (xρx), S simetričnost, A antisimetričnost, T tranzitivnost.

Ekvivalencija = R + S + T  →  klase i faktor-skup A/ρPoredak = R + A + T  →  Haseov dijagram
Zapamti
Relacija ekvivalencije deli skup na disjunktne klase (particija). Kongruencija po modulu n je primer ekvivalencije.

7.Algebarske strukture

Struktura (S, ∘): grupoid (zatvorenost), polugrupa (+ asocijativnost), monoid (+ neutral), grupa (+ inverzni), Abelova grupa (+ komutativnost).

Prsten (R, +, ·): (R,+) Abelova grupa, · asocijativno i distributivno. Polje: prsten u kom svaki ≠0 ima inverz.
Zapamti
U Kejlijevoj tablici: neutral daje red/kolonu jednaku zaglavlju; grupa ako se neutral javlja tačno jednom u svakoj vrsti/koloni; komutativna ako je tablica simetrična.

8.Bulove algebre i mreže

Bulova algebra (B, +, ·, ′, 0, 1): komutativnost, distributivnost, neutrali 0 i 1, komplement x+x′=1, x·x′=0.

Apsorpcija: x + x·y = x  ·  De Morganovi zakoni: (x+y)′ = x′·y′, (x·y)′ = x′+y′
Zapamti
Iz tablice funkcije: SDNF = suma mintermova (gde je f=1), SKNF = proizvod makstermova (gde je f=0). Minimalna DNF preko prostih implikanti.

9.Vektorski prostori

Skup vektora je linearno nezavisan ako α₁v₁+…+αₙvₙ = 0 povlači sve αᵢ = 0. Baza = nezavisan i generatoran skup; dimenzija = broj vektora baze.

Vektori nezavisni  ⇔  rang matrice njihovih koordinata = broj vektora
Zapamti
Potprostor U ⊆ V sadrži 0 i zatvoren je za + i množenje skalarom. U ℝ³ svaka baza ima tačno 3 nezavisna vektora.

11.Karakteristični koreni i vektori

Za matricu A, broj λ je karakteristični koren (sopstvena vrednost) ako postoji vektor x≠0 sa Ax = λx.

Traži se iz jednačine:   det(A − λI) = 0

Skalarni a·b = |a||b|cosφ (a⊥b ⇔ a·b=0); vektorski a×b (⊥ na oba; a∥b ⇔ a×b=0); mešoviti a·(b×c) (komplanarnost ⇔ = 0).
