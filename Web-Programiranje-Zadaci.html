Web — zadaci

Tipični zadaci sa detaljnim postupkom.
✦
1Izbor HTTP metode

Koja HTTP metoda se koristi za kreiranje novog korisnika na serveru?

Rešenje
POST — kreira novi resurs i menja stanje na serveru: POST /users.
2Statusni kod

Koji statusni kod server vraća kada tražena stranica ne postoji?

Rešenje
404 Not Found — greška klijenta (klasa 4xx): resurs nije pronađen.
3JSON za korisnika

Napiši JSON objekat za korisnika: id 42, ime Marina, aktivan, uloge admin i urednik.

Rešenje
{ "id": 42, "ime": "Marina", "aktivan": true, "uloge": ["admin", "urednik"] }
4DOM — izmena teksta

Napiši JS koji nalazi element sa id „poruka“ i menja mu tekst u „Zdravo“.

Rešenje
const el = document.getElementById("poruka"); el.textContent = "Zdravo";
5GET vs POST

Navedi ključnu razliku između GET i POST zahteva.

Rešenje
GET čita podatke, šalje ih u URL-u, idempotentan je i keširа se.POST menja stanje, šalje podatke u telu, nije idempotentan i ne kešira se.
6Zaštita od XSS

Korisnik unosi komentar koji se prikazuje drugima. Kako sprečiti XSS?

Rešenje
Escapuj/sanitizuj unos pre prikaza: pretvori <, >, & u HTML entitete i ne ubacuj sirov HTML.
