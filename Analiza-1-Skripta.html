O čemu je Analiza 1. Analiza proučava granične procese (limese), diferencijalni račun (izvode i njihove primene) i integralni račun (integrale i primene), a na kraju i osnovne diferencijalne jednačine. Svaki pojam prvo objašnjavamo rečima, zatim dajemo formulu i rešen primer.

1.Nizovi i limesi

Niz je funkcija sa skupa prirodnih brojeva. Kažemo da niz an teži ka broju L (konvergira) ako se članovi približavaju L kad n raste. Pišemo:

limn→∞ an = L

Granična vrednost funkcije

Slično, funkcija f teži ka L kad x → a. Kod neodređenih oblika („0/0", „∞/∞") koristimo poznate limese i pravila.

limx→0 sin xx = 1 limx→∞ (1 + 1x)x = e

Neprekidnost

Funkcija je neprekidna u tački a ako je limx→a f(x) = f(a) (nema „prekida", „skoka" ni „rupe").

Zapamti
Kod oblika „0/0" ili „∞/∞" prvo pokušaj sređivanje (skraćivanje, racionalisanje), pa poznate limese; ako ne ide — koristi Lopitalovo pravilo (izvod brojioca podeljen izvodom imenioca).
Rešen primer — limes
limx→2 x² − 4x − 2 = limx→2 (x−2)(x+2)x−2 = limx→2 (x + 2) = 4

2.Izvodi i primena

Izvod meri brzinu promene funkcije (nagib tangente):

f′(x) = limh→0 f(x+h) − f(x)h

Pravila diferenciranja

(u ± v)′ = u′ ± v′ (u · v)′ = u′v + uv′ (uv)′ = u′v − uv′v² složena: (f(g(x)))′ = f′(g(x)) · g′(x)

Ispitivanje toka funkcije

Redosled: domen → nule i znak → parnost/periodičnost → asimptote → f′ (monotonost, ekstremi) → f″ (konveksnost, prevojne tačke) → grafik. Ekstrem: gde f′ = 0 i menja znak.

Zapamti
f′ > 0 → funkcija raste; f′ < 0 → opada. U tački ekstrema f′ = 0. f″ > 0 → konveksna (∪); f″ < 0 → konkavna (∩).
Rešen primer — ekstrem
Za f(x) = x² − 4x + 3: f′(x) = 2x − 4 = 0  →  x = 2 f″(x) = 2 > 0  →  minimum; f(2) = −1

3.Integralni račun

Neodređeni integral je „obrnut" izvodu (primitivna funkcija):

∫ xn dx = xn+1n+1 + C   (n ≠ −1) ∫ 1x dx = ln|x| + C ∫ ex dx = ex + C

Tehnike

Smena (kad je pod integralom funkcija i njen izvod) i parcijalna integracija:

∫ u dv = u·v − ∫ v du

Određeni integral (Njutn–Lajbnic)

∫ab f(x) dx = F(b) − F(a)

Primene: površina ispod krive, zapremina obrtnog tela, dužina luka.

Rešen primer — određeni integral
∫02 x dx = [ x²2 ]02 = 42 − 0 = 2

4.Diferencijalne jednačine

Diferencijalna jednačina povezuje funkciju i njene izvode. Najprostiji tip su jednačine sa razdvojenim promenljivama:

dydx = f(x) · g(y)  →  ∫ dyg(y) = ∫ f(x) dx
Rešen primer — razdvajanje promenljivih
dydx = x · y ∫ dyy = ∫ x dx  →  ln|y| = x²2 + C y = C · ex²2
Zapamti — kako rešiti zadatak
1) Prepoznaj tip (limes, izvod, integral, ODJ). 2) Za limes — sredi pa poznati limes ili Lopitalovo pravilo. 3) Za tok funkcije — idi redom (domen → f′ → f″ → grafik). 4) Za integral — smena ili parcijalna. 5) Proveri rezultat (npr. izvedi nazad).
