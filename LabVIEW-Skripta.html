LabVIEW

Teorija korak po korak, sa sintaksom i rešenim primerima.
✦
← Nazad na predmet
O čemu je predmet. LabVIEW je grafičko programsko okruženje (G jezik) za merenje, akviziciju i upravljanje. Program je virtuelni instrument (VI) sa front panelom (interfejs) i blok dijagramom (logika). Izvršavanje prati protok podataka (dataflow). Svaku temu prvo objašnjavamo rečima, zatim dajemo korake i formulu gde je potrebna.

1.Virtuelni instrument (VI)

Svaki LabVIEW program je VI. Front panel sadrži kontrole (ulazi) i indikatore (izlazi); blok dijagram sadrži logiku (terminale, čvorove i žice). VI ima ikonu i konektor-panel da bi mogao da bude potprogram (SubVI).

Front Panel : Controls (ulaz) + Indicators (izlaz) Block Diagram: Terminals -> Nodes -> Wires Icon / Connector Pane -> SubVI
Zapamti
Kontrola je ulaz (izvor podatka), indikator je izlaz. Isti VI se može ugraditi u drugi VI kao SubVI preko konektor-panela.

2.Dataflow paradigma

LabVIEW koristi protok podataka: čvor se izvršava tek kada su svi njegovi ulazi dostupni; podaci putuju žicama. Nema redosleda linija kao u tekstualnim jezicima — redosled diktira zavisnost podataka.

Zapamti
Dva nezavisna čvora mogu se izvršavati paralelno. Ako čvoru nedostaje bilo koji ulaz, on čeka — to je osnova dataflow modela.

3.Petlje: While i For

While Loop ponavlja telo dok uslov zaustavljanja nije ispunjen (bar jednom se izvrši). For Loop se izvršava tačno N puta (N na terminalu brojanja). Šift-registri prenose vrednost iz jedne iteracije u sledeću.

While Loop : [ ... telo ... ] until (Stop = TRUE) For Loop (N): i = 0 .. N-1 Shift Register: prev -> next
Zapamti
For Loop nad nizom automatski postavlja N na dužinu niza (auto-indeksiranje). Šift-registar inicijalizuj van petlje da izbegneš zaostalu vrednost.

4.Strukture: Case i Sequence

Case struktura bira koji podblok se izvršava prema selektoru (bulov, broj ili enum). Sequence (flat/stacked) nameće redosled kad dataflow nije dovoljan. Event struktura reaguje na događaje sa front panela.

Zapamti
Case struktura mora pokriti sve vrednosti selektora (podrazumevani „Default” slučaj). Sekvencu koristi štedljivo — bolje je redosled nametnuti zavisnošću podataka.

5.Nizovi i klasteri

Niz (array) je uređena kolekcija istih tipova. Klaster (cluster) grupiše različite tipove (kao struktura/record). Klaster se pravi funkcijom Bundle, a rastavlja sa Unbundle.

Array : [x0, x1, x2, ...] (isti tip) Cluster : { number, string, bool } (razni tipovi) Bundle / Unbundle <-> Cluster
Zapamti
Na granici For petlje niz se automatski indeksira (auto-indexing): u svakoj iteraciji uzima se jedan element, a na izlazu se sastavlja novi niz.

6.Akvizicija (DAQ) i uzorkovanje

DAQ (Data Acquisition) čita signale sa senzora preko DAQ kartice (DAQmx). Da bi signal bio verno rekonstruisan, mora važiti Nikvist–Šenonova teorema: frekvencija uzorkovanja mora biti veća od dvostruke najviše frekvencije signala.

DAQmx Create Channel DAQmx Timing (rate = fs) DAQmx Start DAQmx Read (N uzoraka) DAQmx Stop
Zapamti
Ako je f_s ≤ 2·f_max javlja se preklapanje spektra (aliasing) i signal se pogrešno rekonstruiše. Zato se pre A/D pretvarača stavlja anti-aliasing filtar.

7.Filtriranje (FIR/IIR)

Digitalni filtri uklanjaju neželjene frekvencije. FIR (konačan impulsni odziv) nema povratnu spregu i može imati linearnu fazu. IIR (beskonačan impulsni odziv) koristi povratnu spregu — efikasniji, ali može biti nestabilan.

Zapamti
FIR je uvek stabilan i može dati linearnu fazu (bez izobličenja faze); IIR daje strmiju karakteristiku sa manje koeficijenata, ali treba paziti na stabilnost.

8.Grafici i SubVI

Waveform Chart dodaje tačke jednu po jednu i pamti istoriju — pogodan za praćenje uživo. Waveform Graph iscrtava ceo niz odjednom. SubVI je VI ugrađen u drugi VI radi ponovne upotrebe i preglednosti.

Zapamti
Chart čuva internu istoriju i osvežava se tačku-po-tačku; Graph očekuje ceo niz (ili talasni oblik) i ne pamti prethodne pozive. SubVI smanjuje dupliranje koda.
