Matematika 1. razred — Skripta

Pregled šest ključnih oblasti iz matematike za prvi razred gimnazije.
✦
← Nazad na predmet
O čemu je gradivo. Ova skripta pokriva šest osnovnih oblasti prvog razreda: logiku i skupove, realne brojeve, linearne funkcije, kvadratnu jednačinu, stepene i korene, kao i uvod u trigonometriju. Gradivo je objašnjeno jednostavnim jezikom, sa naglaskom na razumevanje osnovnih pojmova.

1.Logika i skupovi

Iskazi i logičke operacije. Iskaz je rečenica koja je ili tačna ili netačna. Osnovne logičke operacije su konjunkcija (∧), disjunkcija (∨), negacija (¬) i implikacija. Skup je zbir različitih elemenata; skupovi se povezuju operacijama unije (∪), preseka (∩) i razlike.

A ∪ B = {x | x ∈ A ili x ∈ B}|A ∪ B| = |A| + |B| − |A ∩ B|
Zapamti
Konjunkcija ∧ je tačna samo kad su oba iskaza tačna; disjunkcija ∨ je netačna samo kad su oba iskaza netačna.

2.Realni brojevi

Skupovi brojeva. Realni brojevi (ℝ) obuhvataju racionalne (ℚ) i iracionalne brojeve. Racionalni brojevi se mogu zapisati kao razlomak a/b (b≠0), dok se iracionalni ne mogu (npr. √2, π). Na brojevnoj pravoj svakom realnom broju odgovara tačno jedna tačka.

|a| = a, ako je a ≥ 0; |a| = −a, ako je a < 0a < b ⇒ a + c < b + c
Zapamti
Apsolutna vrednost broja je uvek nenegativna: |a| ≥ 0 za svaki realan broj a.

3.Linearne funkcije

Oblik i grafik. Linearna funkcija ima oblik y = kx + n, gde je k koeficijent pravca (nagib), a n odsečak na y-osi. Grafik linearne funkcije je prava linija. Ako je k > 0, funkcija raste; ako je k < 0, funkcija opada.

y = kx + nk = (y₂ − y₁)/(x₂ − x₁)
Zapamti
Koeficijent pravca k određuje nagib prave: veće |k| znači strmiju pravu.

4.Kvadratna jednačina

Opšti oblik i rešavanje. Kvadratna jednačina ima oblik ax² + bx + c = 0, gde je a ≠ 0. Rešava se pomoću diskriminante D = b² − 4ac. Ako je D > 0, jednačina ima dva realna rešenja; ako je D = 0, jedno (dvostruko) rešenje; ako je D < 0, nema realnih rešenja.

x = (−b ± √(b² − 4ac)) / 2aD = b² − 4acx₁ + x₂ = −b/a, x₁ · x₂ = c/a
Zapamti
Znak diskriminante D određuje broj realnih rešenja: D > 0 → dva rešenja, D = 0 → jedno, D < 0 → nijedno.

5.Stepeni i koreni

Osobine stepena i korena. Stepen aⁿ predstavlja proizvod broja a sa samim sobom n puta. Osnovna pravila: aᵐ·aⁿ = aᵐ⁺ⁿ, (aᵐ)ⁿ = aᵐ·ⁿ. Koren se može zapisati kao stepen sa razlomljenim izložiocem: a^(1/n) = ⁿ√a.

aᵐ · aⁿ = aᵐ⁺ⁿ(aᵐ)ⁿ = aᵐ·ⁿa^(1/n) = ⁿ√a
Zapamti
Za a ≠ 0 važi a⁰ = 1, a a^(−n) = 1/aⁿ.

6.Trigonometrija — uvod

Trigonometrijske funkcije pravouglog trougla. U pravouglom trouglu, za oštar ugao α definišu se: sin α = naspramna kateta / hipotenuza, cos α = susedna kateta / hipotenuza, tg α = naspramna kateta / susedna kateta. Osnovni identitet: sin²α + cos²α = 1.

sin α = a/c, cos α = b/c, tg α = a/bsin²α + cos²α = 1
Zapamti
Za ugao od 30°, 45° i 60° vrednosti sin, cos i tg su standardne i treba ih znati napamet.
