1Postavljanje modela

Fabrika pravi stolove (profit 3) i stolice (profit 2); ograničenja rada 4x+2y≤ 100, materijala x+y≤ 40. Postavi model.

Rešenje
max z = 3x + 2yuz: 4x + 2y ≤ 100,   x + y ≤ 40,   x, y ≥ 0
2Grafička — teme

Za max z = x + y uz x ≤ 3, y ≤ 4, x,y ≥ 0, nađi optimum.

Rešenje
Dopustiva oblast je pravougaonik; teme (3, 4)zmax = 3 + 4 = 7
3Dopunske promenljive

Rešenje
2x + 3y + s = 12,   s ≥ 0
