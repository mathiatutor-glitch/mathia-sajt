1Enkapsulacija — geter/seter

Napiši klasu koja čuva temperaturu, ali ne dozvoljava vrednost ispod −273,15.

Rešenje
class Temperatura { private double c; public void setC(double v) { if (v >= -273.15) this.c = v; // cuva invariantu } public double getC() { return this.c; } }
2Prepoznaj stub OOP

Metoda glas() u klasi Pas menja nasleđenu glas() iz Zivotinja. Koji stub i mehanizam?

Rešenje
Polimorfizam ostvaren nadjačavanjem (override) — odluka o pozivu je u vreme izvršavanja.
3Preklapanje vs nadjačavanje

Da li su saberi(int,int) i saberi(double,double) u istoj klasi preklapanje ili nadjačavanje?

Rešenje
Preklapanje (overloading) — isto ime, različiti parametri, ista klasa, odluka u vreme prevođenja.
4UML — koja veza?

Klasa Kuca sadrži objekte Soba; sobe ne postoje bez kuće. Koja UML veza?

Rešenje
Kompozicija (pun romb ◆) — deo (Soba) umire zajedno sa celinom (Kuca).
5Složenost petlje

Kolika je vremenska složenost dve ugnežđene petlje, svaka od 0 do n?

Rešenje
for (int i = 0; i < n; i++) for (int j = 0; j < n; j++) radi(); // n * n poziva
6SOLID — prekršaj

Klasa Izvestaj i računa podatke i štampa PDF i šalje mejl. Koji SOLID princip je narušen?

Rešenje
SRP (jedna odgovornost) — klasa radi tri posla. Podeli je na tri klase: proračun, izvoz PDF, slanje mejla.
