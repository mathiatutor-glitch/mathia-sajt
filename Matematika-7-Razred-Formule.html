← Nazad na predmet
Formule na jednom mestu. Ovde su sabrane sve najvažnije formule iz realnih brojeva, stepenovanja, algebarskih izraza, Pitagorine teoreme, mnogouglova i kruga — idealno za brzo ponavljanje pred kontrolni ili test.

1.Realni brojevi

ℝ = ℚ ∪ I (realni = racionalni ∪ iracionalni)|a| = a, ako je a ≥ 0; |a| = −a, ako je a < 0√2 ≈ 1,41; √3 ≈ 1,73; π ≈ 3,14

2.Stepenovanje

aᵐ · aⁿ = aᵐ⁺ⁿ (množenje stepena iste osnove)aᵐ : aⁿ = aᵐ⁻ⁿ, a ≠ 0 (deljenje stepena iste osnove)(aᵐ)ⁿ = aᵐ·ⁿ (stepen stepena)

3.Algebarski izrazi

(a+b)² = a² + 2ab + b² (kvadrat zbira)(a−b)² = a² − 2ab + b² (kvadrat razlike)(a+b)(a−b) = a² − b² (razlika kvadrata)

4.Pitagorina teorema

c² = a² + b² (c je hipotenuza, a i b su katete)a = √(c² − b²) (izračunavanje katete)c = √(a² + b²) (izračunavanje hipotenuze)

5.Mnogougao

Zbir uglova = (n − 2) · 180° (n je broj stranica)Broj dijagonala d = n(n − 3) / 2

6.Krug

O = 2rπ (obim kruga)P = r² · π (površina kruga)
