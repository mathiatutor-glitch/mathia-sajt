O čemu je Analiza 2. Nadograđuje Analizu 1: prvo redovi (numerički, stepeni, Furijeovi), zatim funkcije više promenljivih (parcijalni izvodi, ekstremi), pa višestruki integrali (dvojni i trojni) i na kraju vektorska analiza (teorija polja). Svaki pojam prvo objašnjavamo rečima, zatim dajemo formulu i rešen primer.

1.Brojni i funkcionalni redovi

Numerički red ∑ an konvergira ako niz parcijalnih suma ima konačan limes. Osnovni kriterijumi:

Košijev (koreni): limn→∞ n√|an| = LD'Alamberov (količnički): limn→∞ |an+1||an| = L

Ako je L < 1 red konvergira, L > 1 divergira, L = 1 ne odlučuje.

Stepeni redovi

Poluprečnik konvergencije R:

R = 1limn→∞ n√|an|Tejlorov red: f(x) = ∑ f(n)(a)n! · (x − a)n

Furijeovi redovi

Periodičnu funkciju razvijamo po sinusima i kosinusima:

f(x) = a02 + ∑ (an cos nx + bn sin nx)
Zapamti
Neophodan uslov: ako an ne teži 0, red sigurno divergira.

2.Funkcije više promenljivih

Parcijalni izvod se traži po jednoj promenljivoj (ostale konstantne). Gradijent je vektor parcijalnih izvoda:

∇f = ( ∂f∂x, ∂f∂y )Totalni diferencijal: df = ∂f∂x dx + ∂f∂y dy

Lokalni ekstremi

Stacionarne tačke: ∂f/∂x = 0 i ∂f/∂y = 0. Vrstu određuje Heseova determinanta:

D = fxx · fyy − (fxy)²

D > 0 i fxx > 0 → minimum; D > 0 i fxx < 0 → maksimum; D < 0 → sedlo.

Zapamti
Uslovni ekstrem (uz vezu g = 0) rešava se Lagranžovim množiocima: ∇f = λ ∇g.

3.Višestruki integrali

Dvojni integral računa zapreminu ispod površi z = f(x, y) nad oblašću D:

∬D f(x, y) dx dy

U polarnim koordinatama (x = r cos φ, y = r sin φ): dx dy = r dr dφ.

Trojni: ∭V f(x, y, z) dx dy dz
Rešen primer — dvojni integral
Nad pravougaonikom 0 ≤ x ≤ 1, 0 ≤ y ≤ 2, f = x · y:∫01 ∫02 x·y dy dx = ∫01 x · [ y²2 ]02 dx= ∫01 2x dx = [ x² ]01 = 1

4.Vektorska analiza (teorija polja)

Nad skalarnim i vektorskim poljima definišemo operatore:

gradijent ∇f    divergencija ∇ · F    rotor ∇ × F

Krivolinijski integral radi polja duž krive; površinski integral toka kroz površ. Teoreme povezuju integrale:

Grinova, Stoksova i Gaus–Ostrogradski teorema
Zapamti — kako rešiti zadatak
1) Prepoznaj tip (red, izvod/ekstrem, višestruki integral, polje). 2) Zapiši granice. 3) Izaberi koordinate (Dekartove, polarne, cilindrične, sferne) koje pojednostave granice. 4) Računaj „iznutra ka spolja" i proveri.
