← Nazad na predmet
Formule na jednom mestu. Ovde su prikazane sve ključne formule iz šest oblasti prvog razreda, spremne za brzo ponavljanje pred kontrolni ili pismeni zadatak. Formule su grupisane po temama radi lakšeg snalaženja.

1.Logika i skupovi

A ∪ B = {x | x ∈ A ili x ∈ B}|A ∪ B| = |A| + |B| − |A ∩ B|

2.Realni brojevi

|a| = a, ako je a ≥ 0; |a| = −a, ako je a < 0a < b ⇒ a + c < b + c

3.Linearne funkcije

y = kx + nk = (y₂ − y₁)/(x₂ − x₁)

4.Kvadratna jednačina

x = (−b ± √(b² − 4ac)) / 2aD = b² − 4acx₁ + x₂ = −b/a, x₁ · x₂ = c/a

5.Stepeni i koreni

aᵐ · aⁿ = aᵐ⁺ⁿ(aᵐ)ⁿ = aᵐ·ⁿa^(1/n) = ⁿ√a

6.Trigonometrija — uvod

sin α = a/c, cos α = b/c, tg α = a/bsin²α + cos²α = 1
