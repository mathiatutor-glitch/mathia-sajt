Web programiranje

HTTP, HTML/CSS/JS, DOM, REST i bezbednost — korak po korak.
✦
← Nazad na predmet
O čemu je predmet. Web programiranje pokriva kako klijent (pregledač) i server komuniciraju preko HTTP protokola i kako se gradi web stranica. Obrađujemo HTTP metode i statusne kodove, HTML/CSS/JavaScript, DOM, REST i JSON, kolačiće i sesije, responsivni dizajn i osnove bezbednosti (XSS/CSRF).

1.Klijent–server i HTTP

Web radi po modelu klijent–server: pregledač (klijent) šalje HTTP zahtev, server vraća HTTP odgovor (najčešće HTML, CSS, JS ili JSON). HTTP je bez stanja (stateless) — svaki zahtev je nezavisan.

Zapamti
Pošto je HTTP bez stanja, prijava korisnika se pamti kroz kolačiće/sesije, a ne kroz sam protokol.

2.HTTP metode

Glavne metode: GET (čitanje, bez izmene, idempotentno), POST (kreiranje, menja stanje), PUT (zamena/ažuriranje celog resursa, idempotentno) i DELETE (brisanje). GET šalje podatke u URL-u, POST u telu zahteva.

Zapamti
GET je „bezbedan“ i idempotentan (ponavljanje ne menja stanje); POST nije — dvostruko slanje može napraviti dva zapisa.

3.Statusni kodovi

Server odgovara statusnim kodom. Klase: 2xx uspeh (200 OK), 3xx preusmerenje (301 trajno pomereno), 4xx greška klijenta (404 nije nađeno, 403 zabranjeno), 5xx greška servera (500 interna greška).

Zapamti
Zapamti prve cifre: 2 = uspeh, 3 = preusmerenje, 4 = grešiš ti (klijent), 5 = greši server.

4.HTML — struktura

HTML opisuje strukturu stranice pomoću elemenata (tagova) i atributa. Dokument ima head (meta podaci) i body (vidljiv sadržaj). Semantički tagovi (header, nav, main, footer) poboljšavaju pristupačnost i SEO.

<!doctype html> <html lang="sr"> <head> <meta charset="utf-8"> <title>Naslov</title> </head> <body> <h1>Zdravo</h1> <p>Prvi pasus.</p> </body> </html>
Zapamti
Uvek zatvaraj tagove i koristi jedan h1 po stranici — struktura naslova pomaže čitačima ekrana i pretraživačima.

5.CSS i responsivni dizajn

CSS opisuje izgled — boje, raspored, tipografiju. Responsivni dizajn prilagođava stranicu veličini ekrana pomoću fluidnih mreža i medijskih upita (@media).

/* responsivni dizajn: prelom na malim ekranima */ .grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 16px; } @media (max-width: 600px) { .grid { grid-template-columns: 1fr; } }
Zapamti
Radi „mobile‑first“: prvo stiluj za mali ekran, pa medijskim upitima dodaj pravila za veće ekrane.

6.JavaScript i DOM

JavaScript daje stranici ponašanje. DOM (Document Object Model) je stablo objekata koje predstavlja HTML; preko njega JS čita i menja elemente i reaguje na događaje (klik, unos).

// DOM: nadji element i promeni sadrzaj const el = document.getElementById("poruka"); el.textContent = "Izmenjeno!"; el.addEventListener("click", () => { el.classList.toggle("aktivno"); });
Zapamti
Ne diraj DOM u petlji previše puta — svaka izmena može izazvati preračun rasporeda. Grupiši promene radi brzine.

7.REST i JSON

REST je stil arhitekture gde su podaci resursi dostupni preko URL-a, a HTTP metode definišu operaciju (GET/POST/PUT/DELETE). Podaci se najčešće razmenjuju u JSON formatu.

{ "id": 42, "ime": "Marina", "aktivan": true, "uloge": ["admin", "urednik"] }// REST poziv: GET /api/korisnici/42 fetch("/api/korisnici/42") .then(res => res.json()) .then(data => console.log(data.ime));
Zapamti
Dobar REST URL imenuje resurs, ne akciju: GET /korisnici/42, a ne /dajKorisnika?id=42.

8.Kolačići i sesije

Kolačić je mali podatak koji server postavlja u pregledaču i vraća se uz svaki zahtev. Sesija čuva stanje korisnika na serveru, a kolačić drži samo identifikator sesije. Tako se pamti prijava iako je HTTP bez stanja.

Zapamti
Postavi kolačiće za prijavu kao HttpOnly i Secure — tako ih JavaScript ne može pročitati (zaštita od XSS krađe).

9.Bezbednost: XSS i CSRF

XSS (Cross‑Site Scripting) — napadač ubaci zlonameran skript koji se izvrši u pregledaču žrtve; brani se sanitizacijom/escape korisničkog unosa. CSRF (Cross‑Site Request Forgery) — žrtva nesvesno pošalje zahtev; brani se CSRF tokenom i SameSite kolačićima.

Zapamti
Zlatno pravilo: nikada ne veruj korisničkom unosu. Escapuj izlaz u HTML, koristi parametrizovane upite protiv SQL injekcije.
