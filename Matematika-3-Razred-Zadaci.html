Uči kroz rešene zadatke. Svaki zadatak je rešen korak po korak, kako bi se lakše savladao postupak i primenio na sličnim primerima.

1.Nizovi

Rešen primer
Dat je aritmetički niz čiji je prvi član a₁ = 3, a razlika d = 4. Odredi deseti član niza i zbir prvih deset članova.Zapišemo formulu za opšti član: aₙ = a₁ + (n−1)·d.Uvrstimo n = 10: a₁₀ = 3 + (10−1)·4 = 3 + 36 = 39.Zbir računamo preko formule Sₙ = n·(a₁ + aₙ)/2, pa je S₁₀ = 10·(3 + 39)/2 = 10·42/2 = 210.Rezultat: a₁₀ = 39, a zbir prvih deset članova je S₁₀ = 210.

2.Granična vrednost (limes)

Rešen primer
Izračunati graničnu vrednost lim(x→2) (x² − 4)/(x − 2).Uvrštavanjem x = 2 dobijamo oblik 0/0, pa izraz treba transformisati.Rastavimo brojilac na činioce: x² − 4 = (x − 2)(x + 2).Skratimo zajednički činilac (x − 2): (x − 2)(x + 2)/(x − 2) = x + 2.Sada uvrstimo x = 2: lim(x→2) (x + 2) = 4.

3.Izvod funkcije

Rešen primer
Odrediti izvod funkcije f(x) = x³ − 5x² + 2x − 7.Izvod se računa član po član, koristeći pravilo (xⁿ)' = n·xⁿ⁻¹.Izvod od x³ je 3x², izvod od −5x² je −10x, izvod od 2x je 2, a izvod konstante −7 je 0.Sabiranjem dobijamo f'(x) = 3x² − 10x + 2.

4.Primene izvoda

Rešen primer
Odrediti jednačinu tangente na grafik funkcije f(x) = x² − 3x + 2 u tački x₀ = 1.Izračunamo vrednost funkcije u toj tački: f(1) = 1 − 3 + 2 = 0, dakle y₀ = 0.Nađemo izvod funkcije: f'(x) = 2x − 3.Izračunamo koeficijent pravca u toj tački: f'(1) = 2·1 − 3 = −1.Uvrstimo u jednačinu tangente: y − 0 = −1·(x − 1), odnosno y = −x + 1.

5.Integral — uvod

Rešen primer
Izračunati neodređeni integral ∫(3x² − 4x + 1)dx.Integral zbira je zbir integrala, pa integralimo svaki sabirak posebno.∫3x²dx = 3·x³/3 = x³, ∫−4x dx = −4·x²/2 = −2x², ∫1 dx = x.Sabiranjem dobijamo rezultat: x³ − 2x² + x + C.

6.Geometrija prostora

Rešen primer
Izračunati zapreminu prave kružne kupe čiji je poluprečnik osnove R = 3 cm, a visina H = 4 cm.Zapišemo formulu za zapreminu kupe: V = π·R²·H/3.Uvrstimo date vrednosti: V = π·3²·4/3 = π·9·4/3.Izračunamo: V = 36π/3 = 12π cm³ ≈ 37,70 cm³.
