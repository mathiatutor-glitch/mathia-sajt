1Ojlerov oblik

Napiši z = 1 + i u obliku r eiφ.

Rešenje
r = |z| = √2, φ = 45° = π/4z = √2 eiπ/4
2Koši–Riman

Da li je f(z) = z² analitička?

Rešenje
z² = (x+iy)² = x² − y² + i·2xy → u = x² − y², v = 2xyux = 2x = vy, uy = −2y = −vx ✓ → jeste analitička
3Reziduum (prost pol)

Nađi Res funkcije f(z) = 1z − 2 u z = 2.

Rešenje
Res = limz→2 (z − 2) · 1z − 2 = 1
4Integral po konturi

Izračunaj ∮ 1z dz po jediničnoj kružnici.

Rešenje
Pol u z = 0, Res = 1∮ = 2πi · 1 = 2πi
5Moduo i argument

Za z = −1 + i√3 nađi |z| i arg z.

Rešenje
|z| = √1 + 3 = 2arg z = 120° (drugi kvadrant)
